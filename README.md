## 🚀 Featured Projects

<details open>
<summary><b>🌿 VerdantAI (PlantAI v2) — AI-Powered Plant Disease Diagnostic Platform</b></summary>
<br/>

An automated plant pathologist: users upload a leaf image and get a diagnosis in under two seconds, backed by a fine-tuned EfficientNet-B0 classifier, Grad-CAM explainability, and an LLM-driven treatment recommendation engine.

| | |
|---|---|
| **Stack** | FastAPI · PyTorch · Torchvision · OpenCV · Streamlit · Plotly · ReportLab · SQLite (WAL) |
| **Scale** | 38-class classifier across 14 crop species |
| **Performance** | 180–400ms inference (CPU-bound) · Grad-CAM in <150ms |
| **Security** | PBKDF2-SHA256 (600k iterations) · IP-bound sessions · auto token rotation · login rate-limiting |
| **Impact** | Instant, auditable diagnosis + structured treatment plans without expert access |
| **Repository** | `Coming soon` |

**Why it matters:** Rather than acting as a black box, VerdantAI generates a Grad-CAM heatmap for every diagnosis and runs a 5-tier LLM fallback chain (OpenRouter) to produce structured organic treatments, soil/nutrient guidance, and prevention steps — all backed by full scan history, analytics dashboards, and printable PDF reports.

</details>

<details>
<summary><b>🤝 ShareCircle — Role-Governed, Location-Aware Donation Platform</b></summary>
<br/>

A community resource-sharing ecosystem connecting Donors, Recipients, and NGOs through a request/reservation state machine with privacy-first contact disclosure and spatial matching.

| | |
|---|---|
| **Stack** | FastAPI · SQLAlchemy 2.0 (async) · Next.js 16 · Supabase (PostgreSQL + PostGIS) · Celery · Redis |
| **Scale** | Multi-role platform (donor / recipient / NGO / admin) with full async backend |
| **Performance** | Zero database-locking errors under 20 concurrent users; atomic transactional reservations |
| **Security** | Supabase JWT auth · pessimistic row-locking to prevent double-allocation · phone-number privacy shield |
| **Impact** | Location-aware matching (PostGIS) + automated donation lifecycle from listing to pickup |
| **Repository** | `Coming soon` |

**Why it matters:** ShareCircle solves the real-world coordination problem behind item donation — competing requests, privacy, and proximity — using an explicit request state machine, PostGIS spatial scoring, and a post-commit Celery/Redis pipeline for reliable notifications. Backed by 134 backend tests and 80 frontend Jest tests.

</details>
